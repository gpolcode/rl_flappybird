# rl_flappybird
## Overview  
A browser-based ONNX inference engine running a Reinforcement Learning agent alongside a human player.  
The JavaScript physics math is synchronized 1:1 with the original Python Gymnasium environment to guarantee parity.  

The model training pipeline and dataset generation are closed source.
